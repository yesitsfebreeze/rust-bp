# Testing

Tests live with implementation under #[cfg(test)], including embedded source
fixtures written to temporary checkouts when a compiler or process is needed.

    cargo test --workspace --locked
    just ci
    just smoke

just smoke runs two ignored tests in src/runtime/daemon/mcp/mod.rs.
The lifecycle journey builds an isolated workspace and exercises the real
runtime's stdio MCP connection, tool listing, LSP, live memory, channel reads,
reload, compiler notifications, failure recovery, stop/restart and EOF cleanup.
It verifies the supervisor PID is the MCP PID and its app/language server close.
The stateful journey uses the actual starter and counter module to prove module
swaps preserve PID/state, app rebuilds restore both states, and failed snapshots
leave the old process serving. CI runs both journeys on Windows/Linux/macOS.

For the complete profiling journey:

    just e2e

It runs native benchmarks and both Valgrind modes, checks comparisons, source
context and rankings, and uses a local Jev protocol fixture by default.
Install native Valgrind or start Docker and build the profiler image first.
CHECK_LIVE_JEV=1 switches to the external service and requires TYPESAFE_API_KEY.
just regressions exercises Docker timeout/cancellation cleanup on Unix.

Direct lifecycle invocation (Bash):

    CHECK_JOURNEY=lifecycle cargo test --locked -p daemon --lib mcp::integration_tests::check -- --ignored --nocapture --exact

Tests create owned temporary workspaces and isolated logs, then clean them up.
Intentional compile failures and panic fixtures are expected test evidence.
