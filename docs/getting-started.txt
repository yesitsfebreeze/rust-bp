# Getting started

Read [install.txt](install.txt) to build and register the runtime MCP.
Read [SYSTEM.md](../tools/SYSTEM.md) for the development workflow.

## Layout

    Cargo.toml             app, workspace members, versions and build profiles
    src/main.rs            stateful demo app
    src/modules/counter/   reloadable cdylib with save/restore
    src/runtime/daemon/    runtime, integrated MCP, LSP, channels and profiling
      mcp/                 MCP dispatch and tool implementations
      bin/daemon.rs        one runtime entry point: MCP, CLI and supervisor
      bin/rustc-events.rs  optional compiler event wrapper
      bin/viz.rs           optional terminal activity viewer
    src/runtime/reload/    module ABI, library swaps and app checkpoints
    justfile               build, check and run recipes
    tools/setup.sh         optional project rename and workspace build
    tools/valgrind.Dockerfile  Linux profiler image

Put temporary files and scratch work in tools/tmp/. It is ignored by Git and can
be cleaned periodically after checking that no active task still uses the files.

Tests and fixtures live inside their implementation files under #[cfg(test)].
All crates have ordinary Cargo manifests; no bootstrap is needed for discovery.

## Build and run

    cargo check --workspace --all-targets --locked
    cargo build --release --locked
    cargo run --release -p daemon -- serve
    just ci
    just smoke

MCP starts its supervisor automatically; serve is the standalone terminal option.
Edit src/modules/counter/lib.rs to swap code while keeping the app alive.
Edit src/main.rs to restart with app/module state restored. See [reload](reload.txt).

To rename the app, run bash tools/setup.sh <name>. It updates the app package, runtime
paths, embedded integration checks and README, then builds the workspace and
updates Cargo.lock. It can be run again to rename again. Runtime target names
stay unchanged, so MCP registration still points at daemon. No client settings
are read or written. Bash, Perl and Cargo are required.
